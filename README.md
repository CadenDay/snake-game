# Snake Game

A classic Snake game implementation in Java.

## How to Run

1. Clone this repository
2. Open in Eclipse (or your preferred Java IDE)
3. Run the main class: `SnakeGame.java`

## Features

- Score Tracking
- Collision Detection
- Randomized Apple Spawns
- Dynamic Body Parts
- Custom Game Over Screen

## Controls

- Arrow keys to move

## Built With

- Java
- Eclipse IDE
